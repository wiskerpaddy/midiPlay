# Web MIDI プレイヤー
このプロジェクトは、ブラウザ上にMIDIファイルを読み込み、
Web Audio API（Tone.js および @tonejs/midi）を利用して
手軽に音声を再生・演奏させるためのシンプルなWebアプリケーションです。

## 構成ファイル
- **index.html**: プレイヤーの画面構造（UI）および外部ライブラリ（Tone.js）の読み込み。
- **style.css**: モダンでクリーンなプレイヤーの外観デザイン。
- **script.js**: MIDIファイルのパース（解析）およびシンセサイザーによる再生処理の制御。

## 使い方（セットアップ）
本アプリは、ブラウザのセキュリティ制限（CORS）の関係上、
ファイルを直接ダブルクリックして開く（file:// スキーム）と正常に動作しない場合があります。
必ずローカルサーバーを起動して閲覧してください。

### 1. ローカルサーバーでの起動方法
以下のいずれかの方法で簡単に起動できます。
- **VS Code をお使いの場合**: 拡張機能「Live Server」をインストールし、index.html を右クリックして Open with Live Server を選択します。
- **Python がインストールされている場合**: フォルダを開いてターミナルで以下を実行します。

```bash
python -m http.server 8000
起動後、ブラウザで http://localhost:8000 にアクセスします。
```

### 2. 再生手順
- 画面上の 「MIDIファイルを選択」 ボタンをクリックし、再生したい .mid または .midi ファイルを読み込みます。
- ファイルの解析が成功すると、グレーアウトしていた 「再生」 ボタンが活性化（緑色に変化）します。
- 「再生」 ボタンを押すと、シンセサイザー音源（Tone.PolySynth）によって自動演奏が始まります。

## 技術的な特徴（仕組み）
- **スマートなパース処理**:
読み込んだCDNライブラリのバージョン（Midi または MidiConvert）を自動で判別し、
安全にバイナリデータを解析（パース）します。

- **正確なタイムスケジュール再生**:
MIDIトラック内のノートデータ（音程、ベロシティ、発音タイミング、長さ）を抽出し、
ブラウザのオーディオタイムスタンプと同期させて triggerAttackRelease で正確に発音させます。

- **PWA（Service Worker）対応**:
index.html の末尾に sw.js（サービスワーカー）の登録処理が組み込まれており、
オフライン動作を見据えた設計になっています。

## 注意点
- **無音の場合**: 
ブラウザのポリシーにより、ユーザーが画面（再生ボタン）を
クリックするまで音を鳴らす機能（AudioContext）がブロックされます。
コード側で await Tone.start() を挟んでいるため、必ず「再生」ボタンを押して音声を有効化してください。

- **音色について**: 
現在はデフォルトの矩形波/正弦波シンセ（Tone.Synth）を使用しています。
お好みに応じて音色をカスタマイズすることが可能です。
