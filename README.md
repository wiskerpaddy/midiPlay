# Jazz Score Editor
abcjsを活用した、ジャズ・ミュージシャン/テクニカルライターのための軽量楽譜エディタです。
「外出先のカフェでも、思いついたフレーズを忘れないうちにnoteに書き留める」ことをコンセプトに開発しています。

## コンセプト
- **Speed**: 1ファイル（index.html）ベースの軽量動作。
- **Jazz Focused**: ジャズ特有のアーティキュレーションをボタン一つで挿入。
- **Validation**: 執筆中のリズムミスを防ぐ「拍数チェック」機能。
- **Mobile First**: スマホでの執筆を想定したレスポンシブデザイン。

## 技術スタック
- **Core**: HTML5, CSS3 (Custom Properties), JavaScript (Vanilla JS)
- **Library**: abcjs (Score Rendering)
- **Deployment**: PWA対応予定（オフライン動作対応）

## 主要機能
### 1. リアルタイム・レンダリング
ABC記法で入力すると、即座に下に楽譜が表示されます。L:1/8 (8分音符基準) や M:4/4 などのヘッダーにも対応。

### 2. ジャズ用テンプレートボタン
ジャズの譜面で頻出する以下の記号を、カーソル位置にワンタップで挿入できます。
(3 (3連符)
!>! (アクセント)
u / v (ダウン/アップボウ)
"Doo-Ba" (アーティキュレーション・テキスト)

### 3. リズム・バリデーション
「拍数チェック」ボタンを押すと、設定された拍子（4/4など）に対して、入力された音符が多すぎたり少なすぎたりしないかを小節ごとに自動スキャンします。
